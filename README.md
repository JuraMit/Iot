# Iot

Проект по дисциплине **«Технологии интернета вещей»**.

Цель — создать интерактивную игру «Тетрис» на адресной RGB-матрице 16×16 с использованием микроконтроллера ESP32, физических органов управления и сетевых возможностей платформы.

## Аппаратная часть

- **Микроконтроллер**: ESP32 (рекомендуется DevKit или аналог с достаточным количеством GPIO)
- **Дисплей**: гибкая RGB пиксельная панель 16×16 (WS2812B / NeoPixel)
- **Управление**: концевые выключатели (концевики) в качестве кнопок (влево, вправо, поворот, ускоренное падение, пауза)
- **Питание**: отдельный стабилизированный источник 5 В достаточной мощности (матрица при высокой яркости потребляет заметный ток)

## Варианты реализации

### Вариант 1. Физическое управление + трансляция изображения на телефон

Полностью собирается аппаратная система с концевиками.  
Игра полностью работает локально на ESP32.  
Дополнительно реализуется передача текущего состояния игрового поля (или скриншота/кадра) на смартфон по Wi-Fi.

**Основные возможности:**
- Управление фигурами через концевики
- Отображение игры на матрице 16×16
- Трансляция изображения/состояния игры на телефон (веб-страница с обновляемым полем или WebSocket)

### Вариант 2. Управление через веб-интерфейс (с концевиками или без них)

Система может работать как с физическими концевиками, так и без них.  
Основной способ управления — веб-интерфейс, доступный с телефона или компьютера в одной сети с ESP32.

**Основные возможности:**
- Веб-сервер на ESP32 (Access Point или подключение к домашней сети)
- Полноценный веб-интерфейс управления (кнопки + отображение игрового поля)
- Опциональная поддержка концевиков (можно играть и с телефона, и физически)
- Отображение счёта
- Возможность дальнейшей передачи статистики (MQTT / HTTP)

## Планируемый функционал (общий для обоих вариантов)

- Классическая механика Тетриса (фигуры, вращение, очистка линий, увеличение скорости)
- Сохранение рекорда
